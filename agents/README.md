# نظام المراقبة الأسرية — الدليل الشامل

نظام متكامل لمراقبة الأجهزة الفرعية (كمبيوتر / أندرويد) ورفع كل نشاطها إلى قاعدة بيانات مركزية، بحيث **لا يملك صلاحية عرض السجلات إلا الجهاز الأساسي** بعد تسجيل الدخول.

> **تنبيه قانوني مهم:** استخدم النظام لأغراض مشروعة فقط — رقابة وليّ الأمر على أبنائه القاصرين، أو إدارة أجهزة الشركة بمعرفة العاملين، أو أجهزتك الشخصية. رصد شخص بالغ دون علمه/موافقته مخالف للقانون في معظم الدول (مصر والسعودية والإمارات تشمل ذلك تجريم التجسس والإخلال بالخصوصية). خدمة المراقبة على الأندرويد تظهر كإشعار دائم للمستخدم — هذا مقصود ومتوافق مع سياسات جوجل والقانون.

---

## 1) بنية النظام

```
┌─────────────────────────┐         ┌──────────────────────────┐
│  الأجهزة الفرعية          │         │  الخادم المركزي (Next.js) │
│                          │  HTTPS  │                          │
│  ويندوز: agent.js (Node)  │ ──────► │  /api/device/register     │
│   + إضافة المتصفح        │  مفتاح   │  /api/device/events       │
│     (يرصد الوضع الخفي)    │  لكل     │  /api/device/heartbeat    │
│                          │  جهاز   │                          │
│  أندرويد: تطبيق Kotlin   │ ──────► │  قاعدة بيانات SQLite      │
│   (مكالمات + تطبيقات     │         │  + لوحة تحكم محمية        │
│    + عناوين المتصفح)      │         └──────────┬───────────────┘
└─────────────────────────┘                     │
                                       تسجيل دخول بكلمة مرور
                                                │
                                     ┌──────────▼───────────────┐
                                     │  الجهاز الأساسي (المتصفح)  │
                                     │  - قائمة الأجهزة          │
                                     │  - سجلات كل جهاز مباشرة    │
                                     │  - لا حدث يُعرض بدون دخول  │
                                     └──────────────────────────┘
```

- **التسجيل:** كل جهاز فرعي جديد يحتاج **كود اقتران** (6 أرقام، صالح 10 دقائق، يُستهلك مرة واحدة) تولده من لوحة التحكم → الإعدادات → إقران جهاز. بعد التسجيل يحصل الجهاز على مفتاح API خاص به يستخدمه للأبد.
- **الأمان:** مفتاح الجهاز يسمح **بالرفع فقط** — أي محاولة قراءة السجلات به تُرفض (401). القراءة بكوكي جلسة الجهاز الأساسي المشفرة بـ HMAC بعد إدخال كلمة المرور.
- **تصنيف البحث:** الخادم يستخرج تلقائيًا نص البحث من روابط Google / Bing / DuckDuckGo / Yahoo / Yandex / Baidu / Brave / Ecosia / Startpage ويصنّفها كعملية بحث مستقلة.

## 2) لوحة التحكم (الجهاز الأساسي)

- تعمل حاليًا على رابط المعاينة الخاص بالمشروع — افتحها من أي متصفح على الجهاز الأساسي.
- كلمة المرور المبدئية: `admin123` — **غيّرها فورًا** من الإعدادات (اللوحة تعرض تنبيهًا حتى تغييرها).
- الميزات:
  - **تحديث مباشر:** السجلات تتجدد كل 5 ثوانٍ (يمكن إيقافه من زر التبديل).
  - **فلترة حسب الجهاز:** اضغط على أي جهاز في قائمة الأجهزة.
  - **تبويبات:** الكل / بحث وتصفح / مكالمات / تطبيقات + مربع بحث حر.
  - **إقران جهاز جديد** وإدارة الأجهزة (إعادة تسمية / إيقاف مراقبة / حذف نهائي).
- **نشر الخادم على Vercel مع قاعدة بيانات مجانية (Vercel Postgres / Neon):** الخطوات الكاملة خطوة بخطوة في ملف `DEPLOY-VERCEL.md` المرفق مع المشروع. عنوان الخادم الذي تدخله في البرامج الفرعية هو رابط الموقع المنشور مثل `https://family-monitor-xxxx.vercel.app`.

## 3) الجهاز الفرعي — كمبيوتر (ويندوز)

الملفات في مجلد `windows-agent/`.

### أ) تثبيت إضافة المتصفح (ضرورية لرصد الوضع الخفي)

الإضافة ترسل كل فتحات الصفحات لحظيًا من أي نافذة متصفح، **بما فيها الوضع الخفي**، لأن الالتقاط يتم من داخل المتصفح نفسه وليس من سجل التاريخ.

1. افتح المتصفح → قائمة الإضافات → "إدارة الإضافات" (أو `chrome://extensions`).
2. فعّل **وضع المطوّر (Developer mode)** ثم "تحميل إضافة غير مضغوطة" واختر مجلد `windows-agent/extension`.
3. **الأهم:** من صفحة تفاصيل الإضافة فعّل خيار **"السماح في وضع التخفي / Allow in Incognito"** — بدونه لن تُرصد نوافذ الوضع الخفي.
4. كرر التثبيت في كل متصفح تستخدمه (Chrome، Edge، Firefox، Brave…) — الإضافة متوافقة معهم جميعًا.

### ب) تشغيل البرنامج الرئيسي

1. ثبت [Node.js](https://nodejs.org) نسخة LTS (18 أو أحدث).
2. شغّل `run.bat` — سيثبت الاعتماديات تلقائيًا بـ npm — أول مرة سيطلب: عنوان الخادم + كود الاقتران + اسم الجهاز، ثم يحفظها في `config.json` ويعمل باستمرار.
3. (اختياري) ملف `package.json` يثبت `better-sqlite3` لقراءة سجل المتصفحات احتياط — بدون التثبيت الإضافة تكفي للتغطية الكاملة بما فيها الوضع الخفي.
3. للتشغيل التلقائي عند إقلاع الجهاز: شغّل `install-autostart.bat` بصلاحيات المسؤول.

### ماذا يرصد وكيل الكمبيوتر؟

| المصدر | التغطية |
|---|---|
| إضافة المتصفح | كل المواقع لحظيًا **مع الوضع الخفي** من أي متصفح مثبتت به الإضافة |
| قراءة سجل المتصفحات (احتياط) | Chrome / Edge / Brave / Opera / Firefox — **بدون** الوضع الخفي (هذه المتصفحات لا تكتب الخفي في السجل أصلًا) |
| النافذة النشطة + العمليات الجديدة | فتح أي تطبيق واسمه |
| المكالمات | غير متاحة على الكمبيوتر — تُرصد من الأندرويد |

## 4) أندرويد — تطبيق واحد يعمل الدورين (أساسي + فرعي)

الكود الكامل في `android-agent/` (Kotlin + Gradle جاهز للفتح في Android Studio)، ويوجد ملف **`FamilyMonitor-v1.0.apk` جاهز وموقّع** يمكنك تثبيته مباشرة دون أي بناء.

### أول ما تفتح التطبيق (على أي جهاز)

يسألك مرة واحدة: **«ما نوع هذا الجهاز؟»**
- **جهاز أساسي — لوحة المتابعة:** أدخل رابط موقع اللوحة (Vercel) مرة واحدة، وسيفتح اللوحة **داخل التطبيق نفسه** وتسجل الدخول بكلمة المرور هناك. تذكر الجلسة ولا يطلبها مرة أخرى.
- **جهاز فرعي — سيتم مراقبته:** تظهر شاشة إعداد المراقبة (العنوان + كود الاقتران + اسم الجهاز).

يمكن تغيير النوع لاحقًا من قائمة التطبيق (⋮) → «تغيير نوع الجهاز» في أي شاشة.

### بناء التطبيق بنفسك (اختياري — عند تعديل الكود)

1. ثبت [Android Studio](https://developer.android.com/studio) ثم افتح مجلد `android-agent` (الإعدادات جاهزة لملف Gradle المحلي في `C:\gradle-8.14.3-bin.zip`).
2. من القائمة: **Build → Build Bundle(s)/APK(s) → Build APK(s)** — نسخة Release موقعة بمفتاح `family-monitor.keystore` المرفق.
3. انقل الـ APK للهاتف وثبته (فعّل "تثبيت من مصادر غير معروفة").

### خطوات التفعيل على الهاتف الفرعي (داخل التطبيق نفسه)

1. اختر **«جهاز فرعي»** في شاشة التوجيه.
2. أدخل **عنوان الخادم** و**كود الاقتران** واسم الجهاز ثم اضغط "تسجيل الجهاز وبدء المراقبة".
3. امنح الصلاحية المطلوبة عند طلبها:
   - **سجل المكالمات (READ_CALL_LOG)** → لرصد المكالمات لحظيًا.
   - **الوصول لبيانات الاستخدام (Usage Access)** → اضغط الزر الخاص به وفعّل التطبيق من إعدادات النظام.
   - **خدمة إمكانية الوصول (Accessibility)** → اضغط زر "تفعيل خدمة رصد التصفح" وفعّلها — هذه الخدمة هي التي تقرأ شريط عنوان المتصفحات **وتعمل مع نوافذ التصفح الخفي أيضًا** لأنها تقرأ نص الشريط مباشرة بغض النظر عن وضع التصفح.
4. ستظهر **إشعار دائم** بأن المراقبة نشطة (متطلب نظامي ولا يجوز إخفاؤه).
5. الأحداث تُخزَّن محليًا عند انقطاع النت وتُرفع تلقائيًا عند رجوع الاتصال.

### الصلاحيات ورصدها

| الصلاحية | ماذا ترصد |
|---|---|
| UsageStatsManager | فتح أي تطبيق باسمه وعنوانه (بحث وتصفح تطبيقات الجوال) |
| READ_CALL_LOG + ContentObserver | كل مكالمة: واردة/صادرة/فائتة + الرقم + المدة — لحظيًا |
| خدمة إمكانية الوصول | شريط عنوان المتصفحات (روابط أو نص بحث) حتى في الوضع الخفي |

> ملاحظة صريحة: أندرويد لا يسمح لأي تطبيق بتسجيل "كل حروف الكتابة" على الجهاز إلا عبر خدمات إمكانية الوصول، والرصد هنا مقتصر على شريط العنوان وفتح التطبيقات والمكالمات — أي أن النظام يرصد **أين بحث المستخدم** وليس كل ما يكتبه.

---

## 5) تجربة سريعة بدون تثبيت

من أي كمبيوتر فيه Node.js 18+:

```bash
node simulate-device.js <رابط اللوحة> <كود الاقتران> "جهاز تجريبي" windows
```

سيُسجل جهازًا جديدًا ويرسل أحداثًا تجريبية كل 10 ثوانٍ — ستراها فورًا في لوحة التحكم.

---

## 6) أسئلة شائعة

**هل يمكن للجهاز الفرعي رؤية السجلات أو حذفها؟** لا. البرنامج الفرعي لا يعرض أي بيانات ولا يمتلك إلا مفتاح رفع. الحماية الأقوى على ويندوز: شغّل `install-autostart.bat` بجلسة حساب وليّ الأمر واستخدم حسابًا منفصلًا محدودًا للطفل، وعلى أندرويد فعّل "تأمين التطبيق" من إعدادات الهاتف.

**حذف سجل المتصفح من الجهاز الفرعي؟** لن يفيد — الأحداث أُرسلت للخادم لحظة حدوثها، ومحاولة إيقاف البرنامج ستظهر في اللوحة عبر توقف نبضات الاتصال (آخر ظهور للجهاز).

**أين البيانات؟** قاعدة SQLite مركزية واحدة على الخادم (`db/custom.db`) — انسخها بانتظام إن أردت أرشيفًا دائمًا.
